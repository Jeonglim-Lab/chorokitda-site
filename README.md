# 초록을잇다 홈페이지 (리뉴얼 시안)

`chorokitda.co.kr` 리뉴얼 첫 시안입니다. 빌드 도구 없이 그대로 올릴 수 있는 정적 파일 세트입니다.

## 페이지 구성
1. **히어로** — 화면을 가득 채우는 대형 비주얼(3장 크로스페이드 + 캔버스 모션)과 슬로건
2. **소개** — 브랜드 소개 문장과 키워드(연결·실천·기록)
3. **주요 사업영역** — 3개 사업의 세부 내용(공통 방향·운영 방식·대상별 프로그램·현장 사례·차별점)을 클릭 없이 펼쳐서 표시
4. **현장 비주얼** — 풀블리드 패럴랙스 이미지와 문장
5. **도서·보고서** — 신간 『환경교육사, 준비에서 현장까지』, 국립공원 보고서 카드
6. **함께하는 방식** — 기획·운영 4단계
7. **문의** — 이메일·전화·주소·사업자 정보, 푸터

## 파일 구성
- `index.html` — 페이지 본문(원페이지 구성: 히어로 → 소개 → 사업영역 → 도서·보고서 → 함께하는 방식 → 문의)
- `styles.css` — 디자인·반응형 스타일
- `main.js` — 스크롤 등장 모션, 히어로 슬라이드/캔버스 모션, 모바일 메뉴
- `assets/` — 로고·사진·OG 이미지
- `CNAME` — `chorokitda.co.kr`
- `.nojekyll` — GitHub Pages Jekyll 처리 비활성화

## GitHub Pages 배포
1. 새 저장소(예: `chorokitda`)에 이 폴더의 파일을 그대로 올립니다.
2. Settings → Pages → Source: `Deploy from a branch` / Branch: `main` / `/ (root)`.
3. Custom domain에 `chorokitda.co.kr` 입력 → Enforce HTTPS 체크.
4. 도메인 DNS: `A` 레코드 4개(185.199.108.153 / .109.153 / .110.153 / .111.153), `www`는 `CNAME` → `<계정>.github.io`.
   - 기존 메일(itda@chorokitda.co.kr)이 끊기지 않도록 **MX 레코드는 건드리지 않습니다.**

## 수정이 필요한 자리

- `assets/og.jpg` — SNS 공유 미리보기 이미지
