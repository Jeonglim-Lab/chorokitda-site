# 초록을잇다 홈페이지 (리뉴얼 7차 반영)

`chorokitda.co.kr` 리뉴얼 시안입니다. 빌드 도구 없이 그대로 올릴 수 있는 정적 파일 세트입니다.

## 이번(2차) 반영 내용
- **로고** — 새로 받은 로고 원본(2048px, `IMG_1448`·`IMG_1450`)에서 심볼을 다시 추출해 `logo-mark`, `logo-circle`, 파비콘을 고해상도로 교체. 심볼 옆 `초록을잇다` 워드마크는 **서울남산체(Bold)** 웹폰트(jsDelivr `fonts-archive/SeoulNamsan` 동적 서브셋)로 텍스트 표시
- **메뉴명** — `사업영역` → **`주요사업`** (상단·모바일·푸터·섹션 제목 통일)
- **도서·보고서** — 실제 표지 이미지로 CSS 3D 입체 목업
  - 『환경교육사, 준비에서 현장까지』: 인쇄용 표지 시안(PDF)에서 앞표지·책등을 잘라내어 3D 책으로 구성 (빨간 재단선 제거)
  - 국립공원연구원 보고서: 실제 표지 사진에서 원근 보정해 표지 이미지로 사용, 제목·발행처·발행월 반영
- **2026 실적 추가** — 국가환경교육센터 유아환경학교 수도권역 유치원 4곳 컨설팅, 강북구 마을공동체 `<발밤발밤 – 길여행 씨앗찾기>`(2회차) 및 마을탐방 프로그램 기획안 5개, 해설사 연수
- **사진** — 히어로 4장, 현장 풀블리드(가을 계곡), 사업 3개 카드 이미지를 새 현장·자연 사진으로 교체

## 3차 반영 (v3)
- **로고 잠금(lockup) 간격** — `logo-mark` / `logo-mark-white` 이미지의 좌우 투명 여백을 실제 그림 영역으로 크롭(544×225 → 368×218)하고, `.brand`의 `gap`을 11px → 5px, 심볼 표시 폭을 30px로 조정해 `초록을잇다` 글씨가 심볼 바로 옆에 붙도록 함
- **프로그램 정리** — 주요사업 01의 섹션 소개·설명·태그와 세 번째 카드, `컨설팅 · 연수 · ○○○` 블록 제목에서 해당 프로그램 관련 문구를 모두 삭제(블록은 `컨설팅 · 연수` 2개 카드 구성으로 변경)
- **캐시 갱신** — `styles.css?v=5`, `main.js?v=5`

## 4차 반영 (v4)
- **보고서 문구** — 국립공원연구원 보고서 카드의 배지 `표지 · 편집 · 인쇄 제작` → **`인쇄 · 제작`**, 본문 `표지 디자인과 편집 디자인, 인쇄 제작을 맡았습니다` → **`인쇄와 제작을 맡았습니다`**, 메타 `담당` 항목도 `인쇄 · 제작`으로 정리(일반 출판 서비스 소개 문구의 `표지·편집 디자인`은 그대로 둠)
- **보고서 표지 이미지** — 사진에서 추출한 표지의 하단 좌측 그늘·종이 곡면을 평탄화(플랫필드 보정)하고 가장자리를 흰색으로 정리해 `assets/report-cover.jpg` 교체(원본은 `_source-originals/report-cover-original.jpg`)
- **보고서 3D 목업** — `.book3d--report`의 앞표지·그늘·책등·페이지 모서리 `border-radius`를 0~1px로 줄이고 앞표지에 1px 실선 테두리(`inset box-shadow`)를 넣어 흰 표지가 배경에 묻히지 않는 각진 책으로 보정
- **모바일 로고 균형** — `@media (max-width:640px)`에서 `.brand__mark` 28px, `.brand__name` 1.2rem으로 조정해 심볼 높이(약 16.6px)가 워드마크 글씨 높이(약 18px)에 맞도록 함
- **캐시 갱신** — `styles.css?v=6`, `main.js?v=6`

## 페이지 구성
1. **히어로** — 화면을 가득 채우는 대형 비주얼(8장 크로스페이드 + 캔버스 모션)과 슬로건
2. **소개** — 브랜드 소개 문장과 키워드(연결·실천·기록)
3. **주요사업** — 3개 사업의 세부 내용(공통 방향·운영 방식·대상별 프로그램·현장 사례·차별점)을 클릭 없이 펼쳐서 표시
4. **현장 비주얼** — 풀블리드 패럴랙스 이미지와 문장
5. **도서·보고서** — 3D 책 목업(『환경교육사, 준비에서 현장까지』, 국립공원연구원 보고서)
6. **함께하는 방식** — 기획·운영 4단계
7. **함께하는 사람들** — 분야별 협업 카드 4개(교육·연구 / 생태·역사 트레킹 / 행사·프로그램 / 출판·제작)
8. **문의** — 이메일·전화·주소·사업자 정보, 푸터

## GitHub Pages 배포

1. 저장소 `Jeonglim-Lab/chorokitda-site` `main` 브랜치에 푸시 (CNAME 제외)
2. Settings → Pages → Deploy from a branch / `main` / `/ (root)`
3. `https://jeonglim-lab.github.io/chorokitda-site/` 에서 미리보기 확인
4. 도메인 연결 시 CNAME 추가 + 가비아 DNS(A 레코드 4개, www CNAME) 설정, **MX 레코드는 건드리지 않습니다.**
